Phase 1 — Foundation, Authentication & Media Upload (MVP)

Goal
A user can:
    Register/Login
    Upload an image/video
    Store it in MinIO
    View uploaded files
    Download files
    Delete files
No background processing yet.

Services:
    API Gateway
    Auth Service
    Media Service

PostgreSQL Tables:
    users
    roles
    refresh_tokens
    api_keys
    folders
    media_assets

Media Asset Schema:
    id
    user_id
    folder_id
    file_name
    original_name
    mime_type
    extension
    size
    storage_path
    status
    created_at
    updated_at
